# MSDS 565 — P3: Movie Genre Text Classification (Team teamone)

Predicting movie genres from plot synopses alone, following CRISP-DM across three notebooks: EDA → vectorization, modeling and LLM knowledge distillation → interpretability.

## Data

| Dataset | Role | Link |
|---|---|---|
| `mpst_imdb_movies.csv` (provided) | ~11,800 movies: synopsis, MPST split, IMDB metadata, one 0/1 column per genre | Class Google Drive → `Datasets` |
| MPST: Movie Plot Synopses with Tags | Source of the plot synopses (Wikipedia / IMDB) | https://www.kaggle.com/datasets/cryptexcode/mpst-movie-plot-synopses-with-tags |
| IMDB Non-Commercial Datasets | Source of genres, year, runtime, rating, votes | https://developer.imdb.com/non-commercial-datasets/ |

The plot synopsis is the **only** model input. IMDB metadata is used for analysis and filtering only.

**Setup:** put `mpst_imdb_movies.csv` in a `data/` folder at the repo root. `data/` is git-ignored, so the dataset and the exported `pseudo_labeled.csv` are never committed.

## Environment

```bash
conda env create -f environment.yml
conda activate <env name in environment.yml>
```

**Embedding model:** `sentence-transformers/all-MiniLM-L6-v2` (384 dimensions). It downloads from Hugging Face automatically on the first run. Embeddings are cached outside the repo in `~/.cache/msds565_p3/`.

**LLM teacher:** `llama3.1:8b` (Meta Llama 3.1 8B Instruct) via Ollama. Install Ollama from https://ollama.com, then:

```bash
ollama pull llama3.1:8b
```

## Pipeline — run the notebooks in order

| # | Notebook | Produces |
|---|---|---|
| 1 | `notebooks/P3_MovieGenre-1_EDA_teamone.ipynb` | Metadata distributions, rating by genre, the vote filter (`VOTE_MIN = 1000`, reused by Notebooks 2–3), genre balance and correlations, synopsis length, distinguishing vocabulary |
| 2 | `notebooks/P3_MovieGenre-2_Modeling_teamone.ipynb` | TF-IDF and MiniLM representations, class-weighted logistic regression for **Comedy, Horror, Romance**, LLM pseudo-labels (`data/pseudo_labeled.csv`, not committed), teacher accuracy, leaderboard, and these files in `models/`: `P3_N2_{tfidf,emb-minilm}_logreg_{comedy,horror,romance}.pkl`, `P3_N2_tfidf_vectorizer.pkl`, `P3_N2_tfidf_scaler.pkl` |
| 3 | `notebooks/P3_MovieGenre-3_xAI_teamone.ipynb` | Coefficient plots for each genre, SHAP (LinearExplainer) bar and beeswarm plots for Horror, waterfall plots for a confident hit and a bad miss |

Notebook 3 needs the `models/` files from Notebook 2. Notebook 2's first run embeds the corpus and calls the teacher about 300 times; later runs load both from cache.
